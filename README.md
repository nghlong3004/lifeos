# LifeOS

**LifeOS** is an AI-powered personal life assistant designed to help manage daily habits, personal finances, long-term goals, and continuous self-improvement.

The system uses AI to understand natural language, automate routine tasks, track progress, and provide personalized insights.

## Features

- **Daily Habits & Tasks** — Manage routines, track progress, and receive reminders.
- **Personal Finance** — Track income, expenses, budgets, and savings.
- **Goals & Planning** — Break long-term goals into actionable steps.
- **AI Assistant** — Interact naturally through Telegram.
- **Analytics & Reports** — Visualize progress and export data to Excel.
- **Continuous Improvement** — Articulate, Climb, Verify, Learn.

## Tech Stack

- **API:** Java, Spring Boot, Spring AI
- **Web:** React, TypeScript *(planned)*
- **Database:** PostgreSQL
- **Integration:** Telegram Bot API
- **Build:** Maven
- **Infrastructure:** Docker
